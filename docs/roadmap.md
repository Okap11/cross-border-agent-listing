# cross-border-agent-listing · 功能规划文档（Roadmap）

> 本文档规划项目从当前 MVP（v0.1）到后续版本的迭代路线。所有功能以**保持 Local-First（数据不出本机）、纯前端可独立交付、每版收敛可验证**为原则。
> 状态：本机规划稿（尚未提交 / 推送）。

---

## 1. 项目现状（v0.1 · 已完成）

| 模块 | 已实现能力 | 代码位置 |
|---|---|---|
| 商品管理 | 统一源商品录入 / 编辑 / 删除，IndexedDB 持久化 | `views/ProductEdit.vue`、`stores/product.js`、`utils/db.js` |
| 字段映射 | Ozon / Shein 双平台 Schema，一键导出上架 CSV | `views/FieldMapping.vue`、`utils/field-map.js`、`utils/excel.js` |
| AI Listing 生成 | 接入 Ollama，SSE 流式输出标题 / 五点 / 关键词 | `views/AiGenerate.vue`、`api/ollama.js`、`utils/prompt.js` |
| 竞品评论 RAG | 评论文件导入、本地 TF 检索、问答 | `views/RagAnalysis.vue`、`stores/rag.js`、`utils/vector.js` |
| 部署 | GitHub Pages + Actions 自动部署，在线 Demo 可用 | `.github/workflows/deploy.yml` |

**当前薄弱点（规划的直接依据）**
1. 向量检索为**词频 TF 近似实现**，语义检索能力弱，RAG 效果依赖关键词命中。
2. AI 生成结果为**自由文本**，未结构化回填到商品字段，无法批量复用。
3. Prompt 模板**写死在代码里**，用户不可自定义。
4. 无图片处理、无批量能力、无店铺数据对接。
5. 无单元测试，`components/` 目录尚空。

---

## 2. 规划原则

- **保持 Local-First**：核心数据与推理默认在浏览器本地完成；任何需要云端的能力（如图片 AI、平台 API）一律设计为**可选模块**，用户显式配置后才启用。
- **MVP 收敛**：每个版本只交付 2~4 个可独立验收的功能，避免烂尾。
- **渐进式架构**：底层能力（检索、LLM 适配、存储）设计为可替换接口，先跑通再升级。
- **可演示优先**：优先上线在 GitHub Pages 上能直观展示、别人能上手体验的功能。

## 4. 各版本功能明细

### v0.2 · 体验完善 + 语义检索升级（P0，建议优先）

**目标**：解决当前最影响体验的短板，为后续功能打底座。

| # | 功能 | 说明 | 技术方案 | 复杂度 |
|---|---|---|---|---|
| 4.1 | **语义检索升级** | 用向量检索替换当前 TF 近似检索，显著提升 RAG 召回效果 | Ollama embeddings + 本地向量库（`sqlite-vss` wasm，备选 `hnswlib-wasm` / Web Worker），`utils/vector.js` 改为可替换接口 | 高 |
| 4.2 | **生成结果结构化** | AI 输出解析为 标题 / 五点 / 关键词 字段，可一键回填商品并保存 | 后端无关，前端按模板标记解析；新增"回填"交互 | 中 |
| 4.3 | **Prompt 模板可编辑** | 用户可在界面编辑平台模板并持久化 | 模板存 IndexedDB，`utils/prompt.js` 改为读取存储 + 默认回退 | 中 |
| 4.4 | **xlsx / 模板导入** | 支持导入 xlsx、下载空模板、批量录入 | 复用 `utils/excel.js` | 低 |
| 4.5 | **状态与错误完善** | 统一 loading / 空态 / 错误提示，AI 流式中断恢复 | 全量页面 review | 低 |

**验收标准**：RAG 提问能召回语义相关（非仅关键词命中）片段；AI 生成结果可一键回填商品并持久化；用户可自定义 Prompt 模板；可批量导入商品。

| # | 功能 | 说明 | 技术方案 | 复杂度 |

## 7. 风险与依赖

| 风险 / 依赖 | 说明 | 缓解措施 |
|---|---|---|
| Wasm 向量库体积与兼容性 | `sqlite-vss` wasm 较大，可能影响首屏 | 动态 import + Web Worker 分包；备选 `hnswlib-wasm` |
| 本地模型生成质量 | 标题 / 关键词效果依赖 Ollama 模型能力 | 提供 Prompt 可编辑 + 预设质量模板；文档建议更强模型 |
| 平台 API 授权 | Ozon / Shein 开放 API 需授权，纯前端受限 | v0.5 设计为可选 + 文件导入兜底，不强制后端 |
| 图片 AI 与 Local-First 冲突 | 云端视觉需 Key | 设计为可选模块，默认本地处理，云能力显式开启 |
| 浏览器存储容量 | IndexedDB 大量评论可能占用 | 提供清理 / 数据导出；分页加载 |
